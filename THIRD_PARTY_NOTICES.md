# Third-party software and example inputs

Ligandseek source code and the four released model weights are provided under the [MIT License](LICENSE).

The Point Transformer V3 components are derived from [Pointcept / PointTransformerV3](https://github.com/Pointcept/PointTransformerV3). Copyright (c) 2023 Pointcept. The original MIT notice is preserved in [src/ligandseek/models/PTV3bakcbone/LICENSE](src/ligandseek/models/PTV3bakcbone/LICENSE).

Chimera and CryoAtom2 are external preparation tools. Their executables are not bundled. Obtain Chimera from [UCSF RBVI](https://www.rbvi.ucsf.edu/chimera/) and CryoAtom2 from [its official repository](https://github.com/YangLab-SDU/CryoAtom), under their respective licenses and terms.

Example experimental maps and deposited structures originate from the [EMDB](https://www.ebi.ac.uk/emdb/) and [PDB](https://www.wwpdb.org/). Each example identifies its EMDB/PDB accession. Please cite the corresponding depositions when using those inputs. Prepared receptor predictions, simulations, labels, and released model weights are provided as companion research assets.
